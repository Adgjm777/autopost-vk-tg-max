# Автопостинг медиа: VK + Telegram + MAX

Скрипт берёт случайный файл из папки `media`, публикует его в сообщество ВКонтакте,
в Telegram-канал и в MAX, а после успешной публикации удаляет файл. Если папка пуста —
скрипт просто ждёт пополнения и ничего не публикует.

Подходит для регулярной публикации фото и коротких видео по расписанию.

---

## Что умеет

- Публикация фото и видео в сообщество ВК (от имени сообщества).
- Публикация в Telegram-канал и в MAX.
- Отложенные посты ВК: создать пост «на будущее», не публикуя сразу.
- Паузы между постами, чтобы не выглядело как спам.
- Логи в файл `autopost.log`.

---

## Требования

- Python 3.9 или новее.
- Библиотека `requests` (ставится одной командой).
- ffmpeg НЕ требуется — видео обрабатывает сам ВК.

---

## Установка

1. Скачайте папку со скриптом (или `git clone`).
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Скопируйте `.env.example` в `.env` и заполните значения (см. ниже).
4. Создайте папку `media` и положите туда фото/видео (`.jpg`, `.png`, `.mp4` и т.п.).
5. Запустите:

```bash
python autopost.py
```

---

## Как получить токены

### 1) Токен сообщества ВК (`VK_TOKEN`)

1. Откройте своё сообщество -> Управление -> Работа с API.
2. Нажмите «Создать ключ».
3. Отметьте права: **Управление сообществом (manage), Стена (wall), Фотографии (photos), Видео (video), Сообщения (messages)**.
4. Подтвердите по коду.
5. Скопируйте ключ в `.env` в строку `VK_TOKEN=`.

Нужен именно ключ сообщества: им делаются загрузка фото и публикация на стену.

### 2) Пользовательский токен (`VK_USER_TOKEN`) — только для видео

ВК не позволяет сообществу загружать видео «своим» ключом, поэтому для видео нужен
токен пользователя-администратора с правами `video`.

Если публикуете только фото — оставьте поле пустым.

### 3) Telegram

1. Напишите @BotFather -> `/newbot` -> получите токен вида `123456789:AA...`.
2. Добавьте бота администратором в канал (право публиковать сообщения).
3. В `.env`: `TELEGRAM_BOT_TOKEN=...` и `TELEGRAM_CHANNEL=@имя_канала`.

### 4) MAX

Токен и id канала из кабинета MAX. Если MAX не нужен — оставьте поля пустыми,
публикация в MAX отключится сама.

## Настройки (.env)

| Переменная | Что это |
|---|---|
| `VK_GROUP_ID` | числовой id сообщества (без минуса) |
| `VK_TOKEN` | ключ сообщества |
| `VK_USER_TOKEN` | пользовательский токен для видео (необязательно) |
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `TELEGRAM_CHANNEL` | `@имя_канала` |
| `MAX_TOKEN` | токен MAX (необязательно) |
| `MAX_CHANNEL_ID` | id канала MAX (необязательно) |

Если токен не задан — соответствующая площадка просто пропускается.

## Запуск

```bash
python autopost.py                      # опубликовать 1 случайный файл
python autopost.py --count 3            # опубликовать 3 файла с паузами
python autopost.py --scheduled --delay 180   # отложенный пост ВК примерно через 3 часа
```

---

## Автозапуск по расписанию

**Windows:** Планировщик задач -> «Создать задачу» -> триггер «Каждый час» ->
действие «Запустить программу»: `python`, аргументы `C:\путь\autopost.py`.

**Linux:** `crontab -e` и строка, например, раз в час:

```
0 * * * * cd /path/to/autopost && /usr/bin/python3 autopost.py >> cron.log 2>&1
```

## Типовые ошибки ВК

| Код | Что значит | Что делать |
|---|---|---|
| 5 | токен неверный или истёк | перевыпустить токен |
| 27 | метод недоступен для ключа сообщества | для видео нужен `VK_USER_TOKEN` |
| 1051 | недостаточно прав токена | добавить права при создании ключа |
| 6, 10 | временная ошибка ВК | скрипт повторит сам |

---

## Безопасность

- Никогда не публикуйте `.env` и `tokens.txt` — они уже в `.gitignore`.
- Если токен попал в чужой доступ — сразу перевыпустите (удалите ключ в настройках).
- Скрипт можно передать любой нейросети: по этому README она сама всё установит и настроит.
